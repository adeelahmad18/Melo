# Melo

**Melo** is a modern Android media utility for organizing and downloading media you are authorized to save. Paste a public link, choose an audio or video option, and follow each download with live progress, speed, and time remaining.

Developed and maintained by [Adeel Ahmad](https://github.com/adeelahmad18).

## Download Melo

Download the latest Android APK from the [Melo Releases page](https://github.com/adeelahmad18/Melo/releases/latest).

> Android may ask you to allow installs from your browser or file manager before installing an APK. Only download Melo from this official repository or its official releases.

## What Melo does

Melo keeps the download flow simple:

1. Paste a link or open a public media page in the built-in browser.
2. Select an audio or video quality.
3. Monitor the download from the app or Android notification panel.
4. Find completed media in your chosen download folder.

## Features

- **Quick quality choices** — pick MP3, M4A, 720p, 1080p, or the best available option.
- **Audio-only downloads** — save audio without opening additional format screens.
- **Built-in browser and web search** — open public pages or search the web from Melo.
- **Live download status** — see title, thumbnail, percentage, speed, and estimated time remaining.
- **Download controls** — pause, cancel, retry, open, share, and remove downloads.
- **Favourites and recent links** — keep commonly used links close by.
- **Smart folders** — sort media by source and audio/video type.
- **Storage tools** — review download storage and safely remove incomplete temporary files.
- **Theme controls** — use light mode, dark mode, or your system setting.
- **Clear guidance** — friendly messages for unsupported, sign-in-required, or members-only content.

## Requirements

- Android 8.0 or later
- Internet connection
- Available device storage

Some websites require a supported public media URL. Melo does not bypass subscriptions, paywalls, account logins, DRM, or members-only access.

## Privacy and responsible use

Melo is designed for media you are permitted to download. Please respect the rights of creators, website terms, copyright law, and any access restrictions that apply to the content you use.
