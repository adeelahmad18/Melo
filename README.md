# Melo

Melo is an Android media utility developed and maintained by [Adeel Ahmad](https://github.com/adeelahmad18).

## Download

The current Android APK is provided as a GitHub Release asset. It is kept out of
the source repository because GitHub does not accept APK files larger than 100 MB
in a normal Git push.

## Features

- Paste a link or browse to public media pages
- Choose audio or video quality before downloading
- View live title, thumbnail, progress, speed, and ETA
- Search the web from the in-app browser
- Save favourite links and manage recent downloads
- Organize files by source and media type
- Use light, dark, or system theme
- Safely clean incomplete temporary files
